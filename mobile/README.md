# KrimFish — мобильное приложение

Flutter-приложение доставки морепродуктов: клиентская часть и админка в одном проекте.
Работает с сервером из папки `backend` (Express + PostgreSQL).

## Запуск

1. Поднимите сервер: в папке `backend` выполните `docker compose up --build` (см. `backend/README.md`).
   Чтобы войти администратором, укажите в `backend/.env` `ADMIN_EMAILS` и `ADMIN_PASSWORD` и перезапустите сервер.
2. Запустите приложение:

```bash
cd mobile
flutter pub get
flutter run
```

Адрес сервера выбирается сам: для эмулятора Android это `http://10.0.2.2:3000`, для Chrome/Windows/iOS-симулятора — `http://localhost:3000`.
Для реального телефона укажите адрес компьютера в той же сети:

```bash
flutter run --dart-define=API_URL=http://192.168.1.10:3000
```

Фото товаров хранятся в MinIO. Чтобы телефон их видел, в `backend/.env` задайте `S3_PUBLIC_URL`
(эмулятор Android: `http://10.0.2.2:9000`, телефон: `http://IP-компьютера:9000`) и перезапустите `docker compose up`.

## Вход

Экран входа: email и пароль (с регистрацией), а также «Продолжить через Google» и «Продолжить через VK».
Кнопки Google и VK появляются сами, когда на сервере заданы `GOOGLE_CLIENT_ID` и `VK_CLIENT_ID`.
Роль определяет сервер: адреса из `ADMIN_EMAILS` попадают в админку, остальные — в клиентское приложение.
Телефон для связи с курьером вводится в корзине и сохраняется в профиле.
Для входа через VK укажите ID приложения ещё и в `android/gradle.properties` (`VK_CLIENT_ID`), чтобы приложение
перехватывало возврат из браузера.

## Что внутри

**Клиент:** главная с категориями, каталог с поиском, карточка товара (выбор веса или количества),
корзина (слоты доставки, адрес, промокод — итог считает сервер), заказ со шкалой статусов и отменой,
профиль (имя), мои заказы.

**Админ:** заказы с фильтрами и кнопкой «Принять в работу → Выехал → Доставлен», карточка заказа,
каталог, добавление и редактирование товара с загрузкой фото, сводка («Ещё»).

Статусы заказов подтягиваются каждые 20 секунд. Остаток списывается при заказе и возвращается при отмене — это делает сервер.

## Структура `lib/`

```
main.dart              точка входа, выбор экрана по входу и роли
login_screen.dart      вход и регистрация: email+пароль, Google, VK
core/                  тема, форматирование, адрес сервера, показ ошибок
data/api.dart          HTTP-клиент: токены, автообновление сессии, запросы к API
data/models.dart       модели и разбор JSON
state/providers.dart   состояние на Riverpod: вход, каталог, слоты, корзина, заказы
widgets/               общие виджеты
client/                экраны клиента
admin/                 экраны администратора
```

Токены хранятся в `shared_preferences`. Для боевой версии лучше перенести их в `flutter_secure_storage`
и перейти на HTTPS (сейчас в Android разрешён обычный HTTP для разработки — `usesCleartextTraffic`).
